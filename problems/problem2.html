$$\int_0^1 x^m\ln^n x\ dx$$

Solution

Set $t = -\ln x \Leftrightarrow x = e^{-t} \Rightarrow dx = -e^{-t}\ dt$, therefore \begin{align*} \int_{0}^{1} x^m \ln^n x\ dx &= \int_{\infty}^{0} e^{-mt} \cdot (-1)^n \cdot t^n \cdot \left(-e^{-t}\right)\ dt =(-1)^n\int_{0}^{\infty} e^{-t(m+1)} t^n\ dt. \end{align*} Next set $s=t(m+1) \Leftrightarrow t = s/(m+1) \Rightarrow dt=ds/(m+1)$, \begin{align*} (-1)^n\int_{0}^{\infty} e^{-t(m+1)} t^n\ dt &=(-1)^n\int_{0}^{\infty} e^{-s} \left(\dfrac{s}{m+1}\right)^n\cdot \dfrac{ds}{m+1} =\dfrac{(-1)^n}{(m+1)^{n+1}}\int_{0}^{\infty} e^{-s} s^n\ ds \end{align*} The last integral is in fact definition of gamma function $\left(\Gamma(n)=\int_{0}^{\infty} e^{-s} s^{n-1}\ ds=(n-1)!, n>0\right)$, hence \begin{equation*} \int_{0}^{1} x^m \ln^n x\ dx = (-1)^n\dfrac{n!}{(m+1)^{n+1}}. \end{equation*}
