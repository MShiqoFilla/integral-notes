$$\int \dfrac{dx}{x^2(x^4+1)^{3/4}}$$

Solution

Set $u=-x^{-1}$, we have $du = x^{-2}\ dx$ and $x=-u^{-1}$, therefore \begin{align*} \int \dfrac{dx}{x^2(x^4+1)^{3/4}} = \int \dfrac{du}{\left(\dfrac{1}{u^4}+1\right)^{3/4}} = \int \dfrac{du}{\left(\dfrac{u^4+1}{u^4}\right)^{3/4}} = \int \dfrac{u^3}{(u^4+1)^{3/4}}\ du \end{align*} Now set $z=u^4+1 \Rightarrow dz = 4u^3\ du$, we have \begin{align*} \int \dfrac{dx}{x^2(x^4+1)^{3/4}} &= \int \dfrac{u^3}{(u^4+1)^{3/4}}\ du = \dfrac{1}{4}\int \dfrac{dz}{z^{3/4}} = z^{1/4} + C \\ &= \left(u^4+1\right)^{1/4} + C = \left(1+\dfrac{1}{x^4}\right)^{1/4} + C. \end{align*}
