$$\int_1^\infty\dfrac{\{x\}}{x^3}\ dx$$

Solution

\begin{align*} \int_1^N \dfrac{\{x\}}{x^3}\ dx &= \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{\{x\}}{x^3}\ dx = \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{x-\lfloor x\rfloor}{x^3}\ dx = \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{x-k}{x^3}\ dx \\ &= \sum_{k=1}^{N-1}\left[-\dfrac{1}{x}+\dfrac{k}{2x^2}\right]_k^{k+1} = \sum_{k=1}^{N-1}\left(-\dfrac{1}{(k+1)}+\dfrac{1}{k} + \dfrac{k}{2(k+1)^2}-\dfrac{1}{2k}\right). \end{align*} Since $\frac{k}{2(k+1)^2} = \frac{1}{2(k+1)}-\frac{1}{2(k+1)^2}$, We can confirm that terms in the bracket can be rewritten as $\frac{1}{2}\left(\frac{1}{k}-\frac{1}{k+1}\right)-\frac{1}{2(k+1)^2} $. Putting it back to summation, \begin{align*} \sum_{k=1}^{N-1}\left[\dfrac{1}{2}\left(\dfrac{1}{k}-\dfrac{1}{k+1}\right)-\dfrac{1}{2(k+1)^2}\right] = \dfrac{1}{2}\left(1-\dfrac{1}{N}\right) + \dfrac{1}{2}\left(1 - \sum_{k=1}^{N-1}\dfrac{1}{k^2}\right). \end{align*} Now taking limits $N\rightarrow \infty$ and using Riemann zeta function we get \begin{align*} \int_1^\infty \dfrac{\{x\}}{x^3}\ dx = \lim\limits_{N\rightarrow\infty}\left[\dfrac{1}{2}\left(1-\dfrac{1}{N}\right) + \dfrac{1}{2}\left(1 - \sum_{k=1}^{N-1}\dfrac{1}{k^2}\right)\right] = \dfrac{1}{2}+\dfrac{1}{2}\left(1-\dfrac{\pi^2}{6}\right) = 1-\dfrac{\pi^2}{12}. \end{align*}
