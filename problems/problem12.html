$$\int_1^\infty\dfrac{\{x\}}{x^4}\ dx$$

Solution

\begin{align*} \int_1^N \dfrac{\{x\}}{x^4}\ dx &= \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{\{x\}}{x^4}\ dx = \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{x-\lfloor x\rfloor}{x^4}\ dx = \sum_{k=1}^{N-1}\int_k^{k+1} \dfrac{x-k}{x^4}\ dx \\ &= \sum_{k=1}^{N-1}\left[-\dfrac{1}{2x^2}+\dfrac{k}{3x^3}\right]_k^{k+1} = \sum_{k=1}^{N-1}\left(-\dfrac{1}{2(k+1)^2}+\dfrac{1}{2k^2} + \dfrac{k}{3(k+1)^3}-\dfrac{1}{3k^2}\right). \end{align*} Since $\frac{k}{3(k+1)^3} = \frac{1}{3(k+1)^2}-\frac{1}{3(k+1)^3}$, We can confirm that terms in the bracket can be rewritten as $\frac{1}{6}\left(\frac{1}{k^2}-\frac{1}{(k+1)^2}\right)-\frac{1}{3(k+1)^3} $. Putting it back to summation, \begin{align*} \sum_{k=1}^{N-1}\left[\dfrac{1}{6}\left(\dfrac{1}{k^2}-\dfrac{1}{(k+1)^2}\right)-\dfrac{1}{3(k+1)^3}\right] = \dfrac{1}{6}\left(1-\dfrac{1}{N^2}\right) + \dfrac{1}{3} - \dfrac{1}{3}\sum_{k=1}^{N-1}\dfrac{1}{k^3}. \end{align*} Now taking limits $N\rightarrow \infty$ and using Riemann zeta function we get \begin{align*} \int_1^\infty \dfrac{\{x\}}{x^4}\ dx = \lim\limits_{N\rightarrow\infty}\left[\dfrac{1}{6}\left(1-\dfrac{1}{N^2}\right) + \dfrac{1}{3} - \dfrac{1}{3}\sum_{k=1}^{N-1}\dfrac{1}{k^3}\right] = \dfrac{1}{6}+\dfrac{1}{3}-\dfrac{1}{3}\zeta(3) = \dfrac{1}{2}-\dfrac{1}{3}\zeta(3). \end{align*}
