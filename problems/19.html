$$\int \dfrac{dx}{(3x^2+2)\sqrt{x^2+1}}$$

Solution

Set $x=\tan u \Rightarrow dx = \sec^2 u\ du$, we get \begin{align*} \int \dfrac{dx}{(3x^2+2)\sqrt{x^2+1}} &= \int \dfrac{\sec^2 u}{(3\tan^2u+2)\sqrt{\tan^2u+1}} \ du = \int \dfrac{\sec^2 u}{\left(3\sec^2 u - 1\right)\sec u}\ du = \int \dfrac{\sec u}{3\sec^2 u - 1}\ du. \end{align*} Now multiply both numerator and denominator with $\cos^2u$, \begin{align*} \int \dfrac{\sec u}{3\sec^2 u - 1}\ du = \int \dfrac{\sec u}{3\sec^2 u - 1}\cdot \dfrac{\cos^2u}{\cos^2u}\ du = \int \dfrac{\cos u}{3-\cos^2 u}\ du = \int\dfrac{\cos u}{2+\sin^2u}\ du. \end{align*} Finally Set $t=\sin u \Rightarrow dt = \cos u$, \begin{align*} \int\dfrac{\cos u}{2+\sin^2u}\ du &= \int \dfrac{dt}{2+t^2} = \dfrac{1}{\sqrt{2}}\arctan\left(\dfrac{t}{\sqrt{2}}\right) + C = \dfrac{1}{\sqrt{2}}\arctan\left(\dfrac{\sin u}{\sqrt{2}}\right) + C \\ &= \dfrac{1}{\sqrt{2}}\arctan\left(\dfrac{\sin\left(\arctan x\right)}{\sqrt{2}}\right) + C = \dfrac{1}{\sqrt{2}}\arctan\left(\dfrac{1}{\sqrt{2}}\dfrac{x}{\sqrt{x^2+1}}\right) + C. \end{align*}
