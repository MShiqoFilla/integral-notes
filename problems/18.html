$$\int \dfrac{3x^{13}+2x^{11}}{\left(2x^4+3x^2+1\right)^4} \ dx$$

Solution

Multiply both numerator and denominator with $x^{-16}$, we get \begin{align*} \int \dfrac{3x^{13}+2x^{11}}{\left(2x^4+3x^2+1\right)^4} \ dx = \int \dfrac{3x^{13}+2x^{11}}{\left(2x^4+3x^2+1\right)^4} \cdot \dfrac{x^{-16}}{(x^{-4})^4} \ dx = \int \dfrac{3x^{-3}+2x^{-5}}{\left(2+3x^{-2}+x^{-4}\right)^4} \ dx. \end{align*} Now set $u=2+3x^{-2}+x^{-4} \Rightarrow du = -6x^{-3} -4x^{-5}$. Therefore we get \begin{align*} \int \dfrac{3x^{-3}+2x^{-5}}{\left(2+3x^{-2}+x^{-4}\right)^4} \ dx = -\dfrac{1}{2}\int \dfrac{-6x^{-3}-4x^{-5}}{\left(2+3x^{-2}+x^{-4}\right)^4} \ dx = -\dfrac{1}{2}\int\dfrac{du}{u^4} = -\dfrac{1}{2}\left(-\dfrac{u^{-3}}{3}\right) + C = \dfrac{1}{6}u^{-3} + C. \end{align*} Hence, \begin{align*} \int \dfrac{3x^{13}+2x^{11}}{\left(2x^4+3x^2+1\right)^4} \ dx = \dfrac{1}{6}\left(2+3x^{-2}+x^{-4}\right)^{-3} + C. \end{align*}
