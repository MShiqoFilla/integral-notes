$$\int_0^{2\pi}\lfloor2026\sin x\rfloor\,dx$$

Solution

\begin{align*} A=\int_{0}^{2\pi} \lfloor 2026\sin x\rfloor\ dx &= \int_{0}^{\pi} \lfloor 2026\sin x\rfloor\ dx+\int_{\pi}^{2\pi} \lfloor 2026\sin x\rfloor\ dx. \end{align*} Focus on the second integral on the RHS. Set transformation $x \rightarrow x-\pi$, we get \begin{align*} \int_{\pi}^{2\pi} \lfloor 2026\sin x\rfloor\ dx = \int_{0}^{\pi} \lfloor 2026\sin (x-\pi)\rfloor\ dx = \int_{0}^{\pi} \lfloor -2026\sin x\rfloor\ dx. \end{align*} Therefore \begin{align*} A&=\int_{0}^{\pi} \lfloor 2026\sin x\rfloor\ dx+\int_{\pi}^{2\pi} \lfloor 2026\sin x\rfloor\ dx\\ &=\int_{0}^{\pi} \lfloor 2026\sin x\rfloor\ dx+\int_{0}^{\pi} \lfloor -2026\sin x\rfloor\ dx = \int_{0}^{\pi} \lfloor 2026\sin x\rfloor\ + \lfloor -2026\sin x\rfloor\ dx. \end{align*} Using properties of floor function, that is, \begin{equation*} \lfloor x\rfloor + \lfloor -x\rfloor = \begin{cases} 0 & x \in \mathbb{Z} \\ -1 & x \notin \mathbb{Z} \end{cases} \end{equation*} Hence the integrand is $-1$ except on some points $x\in [0, \pi/2]$ where $2026\sin x \in \mathbb{Z}$ (which the value is 0). Therefore \begin{align*} A=\int_{0}^{2\pi} \lfloor 2026\sin x\rfloor\ dx = -\int_{0}^{\pi}\ dx = -\pi. \end{align*}
